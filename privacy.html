Политика конфиденциальности

Порядок обработки и защиты персональных данных пользователей приложения «Мистер · Репетитор»

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты персональных данных пользователей приложения «Мистер · Репетитор» (далее — «Приложение»).

Оператором персональных данных является Индивидуальный предприниматель (далее — «Оператор»).

Используя Приложение, Пользователь даёт согласие на обработку своих персональных данных в соответствии с настоящей Политикой и Федеральным законом № 152-ФЗ «О персональных данных».

2. Какие данные мы собираем

Оператор может обрабатывать следующие категории данных:

2.1. Данные, предоставляемые Пользователем:

  • имя (или псевдоним);
  • адрес электронной почты (email);
  • пароль (хранится в виде криптографического хеша, недоступного Оператору в открытом виде);
  • данные о учениках (клиентах), которые Пользователь вносит в Приложение по своему усмотрению (имя, расписание, стоимость занятий, заметки);
  • данные об оплатах (обрабатываются платёжным сервисом ЮKassa).

2.2. Данные, собираемые автоматически:

  • дата и время регистрации и последнего входа;
  • техническая информация о браузере и устройстве (в обезличенном виде);
  • IP-адрес (для обеспечения безопасности).

3. Цели обработки данных

Персональные данные обрабатываются в следующих целях:

  • предоставление доступа к функционалу Приложения;
  • аутентификация Пользователя и защита аккаунта;
  • обработка платежей и предоставление доступа к платному функционалу;
  • отправка сервисных уведомлений (напоминания о занятиях);
  • улучшение работы Приложения и устранение ошибок.

4. Передача данных третьим лицам

Оператор не передаёт персональные данные Пользователей третьим лицам, за исключением следующих случаев:

  • Платёжный сервис ЮKassa — для обработки оплат. ЮKassa получает только технические данные, необходимые для проведения платежа, и не имеет доступа к содержимому Приложения;
  • Хостинг-провайдер Supabase — для хранения данных и обеспечения аутентификации. Данные хранятся в зашифрованном виде;
  • По требованию законодательства — если это предусмотрено законом (например, по запросу правоохранительных органов).

5. Хранение и защита данных

Данные хранятся на серверах Supabase, соответствующих требованиям безопасности и использующих шифрование при передаче (HTTPS) и хранении.

Пароли Пользователей хранятся исключительно в виде криптографических хешей (bcrypt). Оператор не имеет технической возможности восстановить исходный пароль Пользователя.

Доступ к данным разграничен с помощью системы Row Level Security: каждый Пользователь имеет доступ только к своим данным.

6. Права Пользователя

Пользователь имеет право:

  • получить информацию о том, какие его данные обрабатываются;
  • потребовать исправления неточных данных;
  • потребовать удаления своих данных (при удалении аккаунта все связанные данные удаляются автоматически);
  • отозвать согласие на обработку данных, направив запрос на email Оператора.

7. Файлы cookie и локальное хранилище

Приложение использует localStorage браузера для хранения:

  • темы оформления (тёмная / светлая);
  • записей ежедневника (если Пользователь их создаёт);
  • токена авторизации (для сохранения сессии).

Эти данные не передаются на сервер и не используются для рекламы.

8. Изменение Политики

Оператор вправе вносить изменения в настоящую Политику. Актуальная версия всегда доступна по адресу privacy.html. Изменения вступают в силу с момента публикации.
